# Private Data Exclusion Proof

## Method

The source commit was treated as read-only. Canonical artifacts were reconstructed from aggregate conclusions under the privacy policy established before reconstruction. No source file was copied into the closeout directory.

Validation combines:

- Exact staged-path allowlisting.
- Comparison of staged paths against the source commit's restricted evidence paths.
- Scan for known private values derived in memory from restricted evidence, without printing or persisting those values.
- Pattern scans for identifiers, emails, credentials, tokens, cookies, authorization material, local receipt paths, receipt formats, and substantial provider prose.
- Manual quotation review confirming that findings are paraphrases rather than reproduced provider explanations.
