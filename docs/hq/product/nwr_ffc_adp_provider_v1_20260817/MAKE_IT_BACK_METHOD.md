# Make-It-Back Method

FFC supplies average ADP and dispersion/range context where available. NWR uses those inputs with the current pick, next owner pick, tier cliff, positional run, and draft round to produce a bounded survival heuristic.

The result is a timing aid, never a promise or calibrated probability claim. Owner-facing outcomes are `LIKELY TO MAKE IT BACK`, `UNLIKELY TO MAKE IT BACK`, or unavailable, with method labeling `HEURISTIC — LOW CONFIDENCE` whenever evidence is insufficient for stronger treatment.
