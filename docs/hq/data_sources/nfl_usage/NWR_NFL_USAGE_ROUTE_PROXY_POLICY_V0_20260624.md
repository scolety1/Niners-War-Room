# NFL Usage Route Proxy Policy V0

Public participation data is not automatically true routes run.

Any route-related metric from public participation must be called a proxy unless exact full routes-run data is verified from an approved source. Do not label proxy TPRR or proxy YPRR as true TPRR or true YPRR.

V0 licensed-data gaps:
- true routes run
- true TPRR
- true YPRR
- full route tree or assignment data when not present in approved public structured sources

Allowed V0 wording:
- route participation proxy
- targets per route proxy
- yards per route proxy
- licensed-data gap for true routes run

Blocked V0 wording:
- true routes run from public participation unless verified
- true TPRR
- true YPRR
