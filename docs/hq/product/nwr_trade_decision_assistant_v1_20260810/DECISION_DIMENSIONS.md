# Decision Dimensions

| Code | Dimension | Contract |
|---|---|---|
| D1 | Best asset | Finished V1 rank-band comparison; rookie/pick challenge stays uncertain. |
| D2 | Established dynasty standing | Sorted ordinal band dominance; no averages. |
| D3 | Youth / career window | Age, rookie status, and explicit lifecycle flags. |
| D4 | Production certainty | Finished V1 coverage count. |
| D5 | Upside / uncertainty | Supported youth/upside exposure without conversion. |
| D6 | Future flexibility | Round, then year, then governed slot certainty. |
| D7 | Position / league fit | 10-team, 1QB, non-PPR, first-down, 3WR, 2FLEX context. |
| D8 | Team-window fit | Contending, Balanced, or Rebuilding; only context-sensitive dimension. |
| D9 | Outcome / risk | Applicable Outcome signals and explicit lifecycle/blocked flags. |
| D10 | Market corroboration | Stale individual secondary signal; no decision-side total. |

Each returns `SIDE_A_CLEAR`, `SIDE_A_LEAN`, `EVEN`, `SIDE_B_LEAN`,
`SIDE_B_CLEAR`, or `UNKNOWN`, plus evidence, confidence, and explanation.
