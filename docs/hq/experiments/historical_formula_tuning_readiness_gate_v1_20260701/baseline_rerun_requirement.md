# Baseline Rerun Requirement

The prior Historical Formula Tuning Sandbox V1 remains useful as directional evidence, but it is not sufficient as the frozen baseline for the next candidate-search lane.

Before any candidate formula comparison, the next phase must create a frozen V3 baseline using the canonical V3 substrate and the split policy from this gate.

Required baseline outputs:

- Baseline metrics for train, validation, and holdout.
- Position-level metrics for QB, RB, WR, and TE.
- Continuous metrics for next-season points and PPG.
- Rank metrics for next-position finish.
- Hit-rate metrics for QB Top 12, RB Top 24, WR Top 36, TE Top 12, and startable hit.
- Evidence that the baseline uses only allowed review-only features and preserves null fences.

No candidate can be described as improved until it beats this frozen V3 baseline on predeclared validation and holdout criteria.
