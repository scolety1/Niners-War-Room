# User quick start

After the final task confirms the stable checkout:

1. Double-click `C:\NWR\Niners-War-Room-V1\scripts\Recover Niners War Room Data Health Receipt.cmd`, review the displayed roots/action, and type `QUARANTINE_CORRUPT_RECEIPT`.
2. Right-click `C:\NWR\Niners-War-Room-V1\scripts\Install Niners War Room Shortcut.ps1` and run with Windows PowerShell as the normal logged-in user; type `INSTALL NINERS WAR ROOM`.
3. Launch `Niners War Room` from Desktop or Start Menu.

No administrator rights are required. If identity, exact HQ, clean tree, Known Folders, receipt state, or shortcut ownership differs, the command stops without guessing.
