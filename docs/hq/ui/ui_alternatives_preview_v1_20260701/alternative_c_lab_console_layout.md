# Alternative C: Lab Console Layout

Alternative C organizes review artifacts and experiments into lanes for datasets, candidates, guardrails, and decisions.

## Preview Intent

- Make artifact status visible before detail.
- Separate datasets from candidate artifacts.
- Show blocked gates clearly.
- Keep human decision notes separate from automated outputs.

## Pages It Could Help

- Development Lab.
- Settings / Data Health.
- Draft Room review sections.

## Pros

- Strong fit for parallel review lanes and artifact packets.
- Makes guardrails visible before experimentation details.
- Scales well when multiple artifacts need review.

## Cons

- Too heavy for everyday Rankings first view.
- Needs restraint so the app does not feel split into a second product.

## Guardrail

Candidate artifacts can be listed as review-only, but no candidate formula output may be promoted, recommended, or wired into default app pages from this layout.
