# Scenario and decision tools

`Saved Scenarios` is presented as **Scenario Playground**: save what-if trades, comparisons, acquisitions, and alternate roster ideas without pretending to calculate unsupported roster impact.

`Decision Journal` is presented as **Decision Tracker**: record the move, NWR advice, final owner choice, and later result to evaluate both NWR and owner reasoning. Existing local persistence and route compatibility are preserved; no automatic learning is claimed.
