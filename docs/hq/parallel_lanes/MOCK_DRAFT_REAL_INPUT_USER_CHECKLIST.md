# Mock Draft Real Input User Checklist

Before a mock draft can run, Mock Draft HQ still needs:

1. The frozen rookie input CSV path.
2. The dropped or available veteran pool.
3. The final draft pick order.
4. Which picks belong to NWR.
5. Current rosters and keepers.
6. Team needs and opponent tendencies.
7. NWR private value source.
8. ADP/market context for opponent behavior only.

Keep all real files local-only. Do not commit them. Missing files are YELLOW
readiness gaps, not permission to fabricate inputs. A schema violation or
ADP/market-to-private-value mix is RED.

No mock draft simulation should run until readiness is GREEN and the operator
explicitly approves the next step.
