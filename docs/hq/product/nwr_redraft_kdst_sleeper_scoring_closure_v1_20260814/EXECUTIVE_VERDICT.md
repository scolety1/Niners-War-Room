# BLOCKED_NWR_REDRAFT_KDST_NO_LAWFUL_PROJECTION_SUPPORT

Fantasy Gamers cannot be mocked completely and truthfully in NWR yet.

The existing 608-row governed Redraft Champion is a QB/RB/WR/TE board only (84 QB, 140 RB, 243 WR, 141 TE; zero K/DST). NWR correctly requires governed point overrides for K/DST and fails closed for the actual 1 K / 1 DEF format.

The nonzero Sleeper contract also includes passing, rushing and receiving two-point conversions. Historical source feasibility identifies their raw fields, but explicitly does not admit them for model use; the Redraft Champion has neither score fields nor a `ScoringSettings` term for them. Mapping those values to zero would be inaccurate.

No K/DST projection, score, tier, mock, recommendation, or roster evaluation was created in this lane.
