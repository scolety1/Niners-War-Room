# Missing Capabilities Discovered from External Assistants

This required addendum comes from comparing NWR with the current `gtonic/nfl_mcp` workflow catalog. It is discovery, not endorsement of its implementations or claims.

| Workflow discovered | NWR state | Adoption |
|---|---|---|
| Full legal lineup analysis | absent | Build in Phase 2 |
| QB/TE multi-week streaming | absent | Extend shared streamer service |
| Roster matchup/SOS and playoff-week planning | partial planning only | Defer until weekly substrate/source approval |
| Bye-week coordination | partial | Reconnect planner and weekly state |
| Opponent weakness scouting | absent as task flow | Reuse for Trade Finder/weekly context |
| Waiver log/re-entry/claim sequencing | raw transactions only | Build read-only decision views |
| FAAB recommendation | absent | Defer until calibrated transaction/budget data |
| High-confidence injury/inactive evidence | absent provider lane | Add only through approved provider registry |
| Projection backtesting/evaluation | inconsistent | Make acceptance infrastructure |
| Provider contract/watchdog checks | partial | Build shared source-health tests |
| Playoff odds/season simulation | not required for completion | Defer; avoid scope inflation |
| Coaching/scheme/news/general web tools | not core owner need | Reject from completion critical path |

The assistant audit strengthens the Phase 2 and provider-observability plan. It does not justify an assistant-first architecture.
