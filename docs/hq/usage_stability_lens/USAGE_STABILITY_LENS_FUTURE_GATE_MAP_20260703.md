# Usage/Stability Lens Future Gate Map

The Usage/Stability Lens is parked as Development Lab review evidence. Any future use requires a separate explicit gate.

## Required Gates Before Further Use

- Separate approval for any app expansion.
- Separate approval for any model input use.
- Separate approval for any rankings impact.
- Separate approval for any live-preview behavior.
- Separate approval before any source-truth promotion.
- Separate approval before any recommendation, hidden sort, trade value, pick value, or draft advice.

## No Silent Promotion

Development Lab parking does not imply readiness. The parked lens may be displayed as dormant review metadata only. It cannot silently become:

- a ranking input;
- a model feature;
- a source-truth dataset;
- a recommendation engine;
- a hidden sort;
- a live preview;
- a main-board formula.

## Stop Conditions

Stop and return to HQ if a proposed lane requires:

- broad formula tuning;
- market/ADP/vendor/projection/rank fields as source truth;
- routes, TPRR, YPRR, ambiguous `rz_att`, unsafe red-zone sidecars, or unsafe current-only context;
- converting missing values to zero;
- player-specific formula exceptions;
- automatic player verdicts or draft advice.

## Allowed Next Step

If Tim wants more review, the only safe next step is a static human-review packet or a very specific future gate with one named failure mode. No more broad tuning is recommended.
