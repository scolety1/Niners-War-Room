# User quick start

NWR is not safe for real one-click launch yet. First resolve the corrupt legacy Data Health receipt through an approved NWR maintenance/recovery path without overwriting either state side. Then run Codex from the actual interactive Windows account so Explorer ownership and Known Folders can be proven, adopt/push the reviewed commits, create `C:\NWR\Niners-War-Room-V1`, and run its installer.

After installation, launch by double-clicking **Niners War Room**. Diagnostic commands from the stable checkout are:

- Status: `C:\NWR_SHARED_DATA\tool_envs\nwr_streamlit_preview\Scripts\python.exe scripts\nwr_desktop.py status`
- Stop: `C:\NWR_SHARED_DATA\tool_envs\nwr_streamlit_preview\Scripts\python.exe scripts\nwr_desktop.py stop`
- Validate data: `C:\NWR_SHARED_DATA\tool_envs\nwr_streamlit_preview\Scripts\python.exe scripts\nwr_desktop.py validate-data`
