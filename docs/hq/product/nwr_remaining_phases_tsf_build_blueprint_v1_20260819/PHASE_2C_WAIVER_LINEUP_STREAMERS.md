# Phase 2C — Waiver, lineup and streamers

Waiver board = available pool + Redraft ROS + weekly context + owner roster needs. Drop candidates disclose depth/bench/bye/replacement context. Add/drop pairs measure legal-lineup and bench marginal improvement. QB/TE/K/DST streamers are position plug-ins; K/DST stays external-consensus-only until admitted evidence exists. Lineup output is a deterministic legal-slot recommendation with close calls, alternatives, risk, confidence and freshness.
