# Model v4 Role Archetype Allowed / Blocked Uses

## Allowed

- Miss taxonomy labels
- Sparse-history warning context
- Low-games warning context
- Low-volume caution context
- High-volume prior-production false-positive analysis
- PYF false-positive / false-negative analysis
- Review-only component signal test slices
- Formula Gauntlet slice reporting after Formula Gauntlet is otherwise cleared
- Review-only evaluation caveats, if separately approved

## Blocked

- Direct ranking boosts
- Direct ranking penalties
- Formula weights
- Production model input
- Hidden sort logic
- Recommendation logic
- Player-level confidence score
- Production approval
- Exact Model v4 replay support
- Source promotion

## Required Language

Use wording like:

`review-only role archetype context`

Do not use wording like:

`approved role score`, `production role input`, `ranking adjustment`, or `player confidence`.
