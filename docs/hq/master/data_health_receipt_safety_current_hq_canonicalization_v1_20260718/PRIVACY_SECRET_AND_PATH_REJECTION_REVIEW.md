# Privacy Secret and Path Rejection Review

The final candidate recursively walks every string in the complete receipt before it can be written. It rejects control characters; authorization and bearer material; API keys; access and refresh tokens; cookies; session identifiers; passwords; credentials; client secrets; raw headers; provider payloads or responses; stack traces and tracebacks; Windows absolute paths; POSIX absolute paths; and parent-directory traversal segments.

Only the fixed relative status path local_exports/refresh_data/latest_refresh_status.json and fixed local storage-boundary value local_exports/refresh_data are admitted. The bounded approved error summaries are derived from a closed error-category map rather than copied from provider or exception payloads.

Adversarial tests covering secret-like field names, secret-like values, provider payloads, raw headers, stack traces, absolute paths, traversal paths, and unauthorized nested structures passed. The staged implementation diff also produced no high-risk secret signature.
