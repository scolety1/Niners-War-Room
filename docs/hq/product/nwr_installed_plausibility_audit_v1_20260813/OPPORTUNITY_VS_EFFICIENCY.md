# Opportunity versus efficiency

The sampled Redraft projection set does **not** support the simple claim that NWR blindly rewards volume.

The working tendency is **opportunity persistence plus production efficiency**, moderated by age, position, and confidence. It can still be wrong when a current role has changed and the governed inputs lag. The right owner action is to manually check routes, target rate, depth chart, and injury context for any large gap — especially Sutton/Davante-style veteran calls and Pierce-style efficiency calls.

Classification: `DOUBLE-CHECK`, with `NOT_ENOUGH_INFORMATION` for historical helpfulness. A prospective timestamped tracking panel is needed before calling this tendency predictive alpha or a systematic defect.
