# Deep Research HQ 1 Charter: Feature Discovery / Source Map / Future Tournament Strategy

## Mission

Deep Research HQ 1 owns broad feature discovery, source mapping, and future feature-tournament architecture for NWR. Its job is to identify source-safe ideas worth testing later, not to run the immediate prior-year baseline challenger.

## HQ 1 Owns

- Broad source discovery.
- Public data source map.
- Metric formula backlog.
- Route, YPRR, TPRR, route participation, air yards, and related proxy research.
- Source status matrix.
- Future candidate metric registry.
- Future feature tournament methodology.
- Validation methodology and baseline ladder design.
- Longer-term source-safe feature discovery roadmap.

## HQ 1 Does Not Own

- Immediate prior-year baseline challenger.
- Production Rankings Backtest V1 implementation changes.
- HQ 2 tournament scorecards.
- HQ 2 miss taxonomy artifacts.
- Production model tuning.
- Production formula changes.
- Rankings changes.
- App/UI integration.
- Source promotion.

## Allowed Inputs To Read

- Production Rankings Backtest V1 packet.
- Historical Model v4 Replay Substrate packet.
- Advanced Metrics, PFR, NGS, CFBD, NFLVerse, DynastyProcess, injury/availability source gates.
- Deep research reports already accepted by HQ.
- Existing historical fantasy foundation docs.

## Allowed Outputs

- Review-only source maps.
- Review-only candidate metric registry.
- Review-only source status matrix.
- Review-only feature coverage questions.
- Review-only future tournament strategy.
- Prompt packets for future research agents.

## Forbidden Outputs

- Production formula edits.
- Production rankings edits.
- App or UI edits.
- Runtime service edits.
- Source-truth registry edits.
- Source promotion.
- Backtest/tournament execution for the immediate prior-year challenger.
- Player recommendations, boosts, winners, trade logic, draft logic, or decision logic.

## Parallel Work Rule

HQ 1 may run in parallel with HQ 2 only when it writes to its own review packet folder and does not touch HQ 2 tournament scripts, scorecards, miss taxonomy files, or prior-year challenger artifacts.

## Success Criteria

HQ 1 succeeds when it produces a source-traced future discovery registry that is useful for later tournaments without changing any production behavior or colliding with HQ 2's immediate challenger lane.
