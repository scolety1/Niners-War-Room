# V1 scope freeze

## Frozen V1 definition

V1 is a reliable, transparent, locally runnable dynasty decision-support application using already admitted data and accepted behavior. Supported surfaces disclose source, trust, freshness, missingness, and review state. V1 does not imply that every optional or future capability is populated.

## Included

- Canonical Dynasty Rankings and Player Compare with governed display/trust behavior.
- Manual Trading Lab without saved-scenario persistence.
- Live Draft, Mock Draft, Draft Analyzer, and existing local state behavior.
- Explicit Refresh Data and read-only Settings / Data Health.
- Manual/display-only roster and planning/deadline surfaces.
- Review-only Development Lab, Evidence, diagnostic, and freeze surfaces.
- Spreadsheet-safe Development Lab and Draft Freeze CSV output.
- Existing identity, source admission, formula/ranking, trust, freshness, and security contracts.

## Excluded or parked

Automated roster hydration, Trading Lab saved scenarios, exact rookie evidence hydration, permission-blocked route metrics, plugin recommendations, new formula challengers, future 2026 outcome tuning, private LocalData content, cloud/cross-device durability, and automatic commit/push.

## Freeze rule

After this packet, a V1 change is admissible only to fix a crash, security vulnerability, data-integrity defect, broken supported workflow, materially false trust/freshness claim, accessibility blocker, or clean-checkout/Hermetic failure. It must be narrow, evidence-backed, independently reviewed, and must not require a new source, identity mapping, formula, ranking, provider, feature, or persistence decision. Everything else enters the governed post-V1 backlog.
