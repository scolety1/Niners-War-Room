# External Signal Governance Boundary

## Controlling rule

NWR's base score remains controlling and separately reproducible. Plugin output has `0%` production influence and must not affect formulas, rankings, recommendations, sorting, filters, confidence, source admission, or persisted product state.

## Weight decision

- Production external influence: `0%`
- Research weight `2.5%`: `NOT_JUSTIFIED`
- Research weight `5%`: `NOT_JUSTIFIED`
- Numerical blend constructed: `NO`
- Qualifying numerical signal demonstrated: `NO`

Immediate repeatability is not equivalence, calibration, or validation. General statistics are not a comparable dynasty-value scale. A provider result cannot become a hidden signal merely because it appears directionally plausible.

## Forbidden influence paths

Plugin output must not be used as a numerical formula input, ranking component, trade-winner label, player rank, production recommendation, sorting key, filter key, hidden confidence signal, persistent disagreement panel, roster-specific truth, source-admitted datum, or fallback when NWR evidence is missing.

## Manual boundary

Manual use is human-readable consultation only. It must remain visibly approximate, retain the capability-specific caveats, and never overwrite NWR's deterministic result. FantasyBot consultation must always state that exact NWR scoring and league context are unsupported.

## Reconsideration

Any numerical influence requires a new preregistered gate demonstrating a documented comparable scale, exact or bounded NWR scoring support, relevant dynasty and roster context, reproducible source-as-of and version metadata, source attribution, and sufficient persistent-use rights. A provider-change trigger alone permits testing; it does not grant admission.
