# Per-league platform selection

Auto selects Sleeper for Sleeper profiles, ESPN for ESPN profiles, FantasyPros for FantasyPros profiles, and Consensus for local/manual/unknown profiles. A league can explicitly select Auto, Consensus, Sleeper, ESPN, FantasyPros, or Disabled/use FFC.

Fantasy Gamers remains a Sleeper profile, so Auto resolves to Sleeper. The selection changes only that league’s use of the shared snapshot.
