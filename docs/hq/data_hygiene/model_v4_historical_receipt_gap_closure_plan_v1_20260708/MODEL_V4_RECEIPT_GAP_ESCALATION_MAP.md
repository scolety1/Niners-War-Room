# Model v4 Receipt Gap Escalation Map

## Data Hygiene Can Own

- receipt inventory
- source trace
- hash and schema checks
- local artifact availability ledger
- component-to-current-board equivalent mapping
- missingness and leakage reviews
- source/use-gate classification
- bounded recovery search plans

## Requires Master HQ Approval

- use of recovered local artifacts as canonical evidence
- regeneration contracts
- exact Model v4 replay scope
- Formula Gauntlet tournament execution
- challenger-score replacement for missing exact Model v4 receipts
- source promotion
- model/ranking/app behavior changes
- production-active review

## Requires Route Recovery

- route denominator source
- YPRR/TPRR field admission
- route licensing/use-rights proof
- route identity and coverage audits

## Requires Formula Gauntlet Lane

- tournament configuration
- candidate formula definitions
- scoring harness
- PYF comparison contract execution
- sparse-history and decline-harm test execution

## Requires Old Local Files / Handoff

- historical current-value output folders
- season-by-season board outputs
- component receipt sidecars
- candidate overlay rows
- shadow sidecars
- original `veteran_player_inputs.csv` or equivalent historical age sidecar

## Should Remain Blocked

- any missing receipt with no source trace
- any recovered file with unclear acquisition/provenance
- any field requiring name-only identity joins
- any current-only context used historically
- any output requiring formula tuning or tournament execution to create
