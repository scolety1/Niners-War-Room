# Blocked Formula Family Report

Blocked in the next phase:

- Any production formula change.
- Any model training, model tuning, or learned black-box model.
- Any unconstrained optimizer that searches arbitrary weights without predeclared bounded families.
- Routes, route participation, route proxies, TPRR, and YPRR.
- Ambiguous `rz_att` or any normalized red-zone attempt substitute.
- Red-zone sidecar fields until a separate source and readiness gate admits them.
- Market, ADP, vendor, projection, rank, ranking, hidden-sort, or recommendation fields as source truth.
- Current-only roster, status, injury, depth, schedule, bye, or next-game context as historical features.
- Injury-risk, durability, medical, comeback, or availability-risk formulas.
- Missing-as-zero variants for null-fenced fields.
- Candidate families that improve only aggregate metrics while failing position-specific holdout gates.

These blocks are mandatory stop conditions, not tuning preferences.
