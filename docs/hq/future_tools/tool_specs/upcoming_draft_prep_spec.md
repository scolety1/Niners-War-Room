# Upcoming Draft Prep Spec - Safe V0

## Purpose

Upcoming Draft Prep is a Development Lab planning workspace for manually preparing the next draft. It collects setup checks, roster need notes, pick inventory notes, a manual prospect watchlist placeholder, mock draft scenario notes, open questions, and data readiness checks.

## Allowed In Safe V0

- Manual checklist rows.
- Manual roster need notes.
- Manual pick inventory rows.
- Future picks from the Live Draft runtime event log as manual/local context only.
- Manual rookie/prospect watchlist notes.
- Manual mock draft scenario notes.
- CSV downloads of entered planning rows.

## Not Allowed

- Rookie rankings.
- Class-strength grades.
- Prospect model scores.
- Player recommendations.
- Position target recommendations.
- Pick valuation.
- Trade valuation.
- CFBD or NFL usage promotion.
- DynastyProcess, ADP, or market hidden logic.

## Data Policy

Manual entries are not saved after reload unless exported. Live Draft runtime context is manual/local state and not official source truth. CFBD/prospect data remains review-only unless separately approved.

## Future Gates

Any future automation requires explicit approval for source truth, model input, display policy, validation, and human review workflow.
