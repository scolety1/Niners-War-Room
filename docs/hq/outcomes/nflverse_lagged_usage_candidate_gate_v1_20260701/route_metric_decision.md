# Route Metric Decision

Decision: `EXCLUDED_OPTIONAL_QUARANTINED_OR_NO_SAFE_SOURCE`

Route metrics do not block the main lagged usage phase. True routes, TPRR, and YPRR remain excluded because no safe admitted rights-cleared source and denominator policy exists.

Do not create fake route proxies from participation data. Public participation context can be reviewed separately, but it cannot be converted into true routes, TPRR, or YPRR in this phase.
