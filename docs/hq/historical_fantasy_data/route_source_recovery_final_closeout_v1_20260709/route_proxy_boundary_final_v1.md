# Route Proxy Boundary Final V1

## Boundary

Route-like proxies remain allowed only as explicitly labeled proxies. They are not true `routes_run`, YPRR, or TPRR.

## Proxy Or Context Metrics

The following may remain proxy/context concepts if already used in review-only or source-readiness work:

- targets per team pass attempt
- receiving yards per team pass attempt
- first downs per target
- first downs per team pass attempt
- air yards per team pass attempt
- targets per offensive snap
- receiving yards per offensive snap
- receiving first downs per offensive snap
- snap counts
- route participation labels
- primary-receiver route labels

## Non-Denominator Rule

None of these metrics can be relabeled as:

- `routes_run`
- true route denominator
- true YPRR denominator
- true TPRR denominator
- admitted route source

## nflverse Boundary

nflverse participation and related public package data can be valuable because they are reproducible and identity-safe. That does not make the `route` label a full eligible-player routes-run denominator. It remains a primary-receiver route label or participation/context field unless nflverse later publishes a documented full routes-run denominator.

## Closeout Instruction

The closeout preserves proxy honesty. Any future model, rankings, formula, UI, or source-truth work must keep proxy labels explicit unless a separate source-admission lane admits a true route denominator source.
