# Tasks Data Hygiene Does Not Own

Data Hygiene does not own final product, ranking, formula, model, app, or canonical decisions.

## Not Owned

- source promotion
- production/model-use approval
- production ranking approval
- app/runtime behavior approval
- ranking changes
- formula tuning
- formula tournaments
- formula winner selection
- hidden sort logic
- recommendation logic
- model weight changes
- canonical merges
- remote pushes unless explicitly approved for a bounded action
- production activation
- production accuracy claims
- final Master HQ promotion decisions

## Required Handoff

If a Data Hygiene packet creates evidence that might affect any not-owned task, hand off to Master HQ using `DATA_HYGIENE_HANDOFF_TEMPLATE.md`.

## Non-Substitution Rule

Data Hygiene must not convert:

- review-only into production-approved
- display-only into model input
- missing into zero
- name-only into identity-safe
- source-visible into source-admitted
- useful dashboard context into proven accurate model input
