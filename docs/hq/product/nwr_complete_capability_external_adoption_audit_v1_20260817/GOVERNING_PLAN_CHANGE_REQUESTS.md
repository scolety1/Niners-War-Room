# Governing Plan Change Requests

The governing plan remains authoritative. These are owner-requested clarifications, not silent edits.

## CR-1 — make candidate adoption Phase 0 explicit

Add a first gate to reconcile the clean `9cb6eaf...` desktop descendant and installed authorities into trusted HQ before new product work. Reason: otherwise implementation will duplicate or conflict with installed capabilities.

## CR-2 — formalize shared provider snapshots

Require a common provider registry/snapshot contract for Market, ADP, projections, injury, weather and other external evidence: source, scope, terms receipt, hash, generated/fetched time, coverage, freshness and fallback.

## CR-3 — split Beat ADP into value and timing

Codify `NWR View` versus `Draft Timing`; forbid expected-pick/survival from becoming ranking authority. Probability claims require calibration.

## CR-4 — put Weekly before Trade Finder

After Draft Room, implement lineup/waivers/streamers before Trade Finder. It completes the seasonal Redraft owner loop and establishes reusable roster/availability/provider contracts.

## CR-5 — replace tier acceptance criteria

Require position-first, evidence-backed and refresh-stable tiers. Permit 1A/1B/1C only when supported, never as a required output shape.

## CR-6 — assistant is optional and downstream

Clarify that MCP/chat is a bounded query/explanation surface over deterministic services, not the product architecture or an analytical authority.

If the owner rejects any request, retain the original plan language and adjust the roadmap explicitly. No request in this file is approved merely by committing the audit.
