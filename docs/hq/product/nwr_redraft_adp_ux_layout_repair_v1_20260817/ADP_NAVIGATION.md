# ADP navigation

`League → ADP Providers` is the dedicated provider surface.

It contains the FFC refresh action, paste-platform table flow, local CSV import entry, active source, priority, freshness, source date, match counts, source notes, and clear-active-provider action. `Profile & Scoring` remains focused on league configuration.

The paste copy explicitly lists Consensus, Sleeper, ESPN, and FantasyPros. Selecting Sleeper is described as `Owner-imported Sleeper ADP`; it uses owner-pasted data and makes no Sleeper ADP API claim.
