# Parking Lot and Reentry Triggers

Items remain parked until the exact trigger is present. A trigger permits reassessment; it does not automatically authorize implementation.

| Parked item | Current classification | Exact reentry trigger | First safe action after trigger |
|---|---|---|---|
| Player Compare saved worksheet/export | `NEEDS_DESIGN_FIRST` | Approved schema defining manual versus derived fields, redaction/privacy, stable keys, stale-key behavior, and neutral copy | Documentation-only design contract |
| Hermetic draft/local-artifact fixtures | `READY_NOW_MODERATE_RISK` | Selected after higher-value lanes, with an inventory of every ignored/local dependency and explicit synthetic-fixture authority | Focused fixture implementation lane |
| Development Lab canonical artifact navigator | `NEEDS_DESIGN_FIRST` | Confirmed stale/superseded link inventory and an owner-approved canonicality source | Display-only design lane |
| Broad Streamlit deprecation cleanup | `PARTIAL_EXISTING_IMPLEMENTATION` | Pinned supported Streamlit version, migration guidance, warning baseline, and bounded page/test scope | Compatibility lane, not mixed with product work |
| Live Draft route/restart repair | `NEEDS_DESIGN_FIRST` | Deterministic reproduction including route, restart sequence, logs, and expected navigation behavior | Diagnostic lane before any fix |
| Navigation alias/wrapper consolidation | `NEEDS_DESIGN_FIRST` | Route ownership map, compatibility commitments, usage evidence, and rollback plan | Documentation/design lane |
| Root workflow and page-name normalization | `NEEDS_HUMAN_REVIEW` | Canonical document/page owners explicitly identified | Documentation-only proposal |
| Worktree administration | `NEEDS_HUMAN_REVIEW` | Explicit operator authorization, ownership inventory, and per-path safety verification | Separate administrative operation; never bundled with product work |
| Roster hydration implementation | `NEEDS_DESIGN_FIRST` | Approved design for admitted inputs, stable identities, missing/empty/stale pack behavior, manual overrides, fixtures, and rollback | Bounded implementation from the later design verdict |
| Canonical lineup-slot support | `NEEDS_DATA_OR_SOURCE_GATE` | Human-confirmed league schema, provenance, migration, validation, and missing-rule behavior | Data-contract design lane |
| Manual contender/rebuilder labels | `NEEDS_HUMAN_REVIEW` | Human ownership, neutral semantics, no automated classification, and persistence/display rules | Design-only lane |
| Replacement-level presentation | `NEEDS_DATA_OR_SOURCE_GATE` | Authorized baseline, canonical lineup rules, temporal validation, and formula-governance approval | Model/data design; not product implementation |
| Rookie administrative navigator | `DEFER_UNTIL_CANONICAL_ENDPOINT_METADATA` | A concrete navigation defect or all queue reentry metadata; no player/mapping/authority effect | Documentation-only repair if still useful |
| Rookie queue closure | `DEFER_UNTIL_CANONICAL_ENDPOINT_METADATA` | Exact opaque endpoint ID; exact endpoint family; exact endpoint-family relationship; endpoint rights; endpoint privacy; artifact-endpoint relationship; evidence hash/receipt; explicit zero authority/use-permission effects | New evidence reconciliation; no automatic closure |
| Flaim reentry | `DEFER_UNTIL_PROVIDER_CHANGE` | Documented provider capability or correction satisfying the plugin closeout | Narrow capability review only |
| FantasyBot reentry | `DEFER_UNTIL_PROVIDER_CHANGE` | Documented provider capability or correction satisfying the plugin closeout | Narrow capability review only |
| Formula/prospective evaluation | `DEFER_UNTIL_2026_OUTCOMES` | Season-complete 2026 outcomes and explicit evaluation authorization under the closeout | Outcome evaluation against byte-preserved freezes |
| New source proposal | `NEEDS_DATA_OR_SOURCE_GATE` | A material product need that existing admitted facts cannot satisfy plus rights, privacy, provenance, freshness, failure, and rollback evidence | Documentation-only source-governance review |

## Non-triggers

The following do not reopen a parked lane:

- an old ready-to-paste prompt;
- a numerically high score with an unsatisfied governance gate;
- external web research or provider contact by itself;
- a convenient but unverified player-name match;
- a desire to make tests green by weakening assertions;
- the existence of a manual plugin workflow;
- a single transient route observation without reproduction;
- the availability of a frozen comparator before outcomes;
- an ignored local export in one operator's environment.
