# NWR V1 known limitations

- Exact historical Model v4 replay is unavailable. Historical aging evidence
  is review-only and no age challenger is admitted.
- The 37-player older-band list is a human-review queue with no production
  effect.
- LocalData verification is blocked with exit 4 when the authorized local pack
  is absent. This is not bypassed.
- Trading Lab is manual. It does not persist trades, submit offers, calculate a
  private value, or issue final advice.
- Manual roster tools do not hydrate or synchronize a roster automatically.
- Refresh Data cannot promote sources or change ranks/models automatically.
- Parked, legacy, development, and review-only surfaces remain non-production
  or compatibility-only as labeled.
- Missing evidence stays Not enough information; it is not inferred as zero or
  healthy.
- The desktop app depends on local Windows runtime ownership and port 8520.
  RECOVERY_REQUIRED may need a second canonical Stop after an app-browser exits.
- Automatic Git pull, commit, push, merge, source promotion, and provider calls
  remain disabled.

Production ranking change: NONE.
