# Trade System Findings

NWR already has the correct trade authority shape: multi-dimensional evidence for established standing, youth, production certainty, upside/uncertainty, future flexibility, league fit, team window, outcome risk, market corroboration, rookie-veteran bridging and accept/counter/reject families. It intentionally avoids a fake universal package score.

Do not build another Trade Calculator. External calculators based on summed market values or arbitrary consolidation taxes are weaker.

## Build around it

- Trade Finder: search opponent rosters for packages that improve declared owner needs while respecting both teams' fit.
- Opponent Targets: team weakness, surplus and window views.
- Counteroffers: smallest evidence-backed changes that move a rejected offer into a viable family.
- Roster impact: before/after starters, depth, picks and immediate/medium-term evidence.

The MIT keeper trade machine supplies only a useful package-enumeration/target UX pattern. Keep NWR valuation and authority labels. Build this after shared roster/market contracts and weekly/draft workflows, because those contracts prevent duplicate integration work.
