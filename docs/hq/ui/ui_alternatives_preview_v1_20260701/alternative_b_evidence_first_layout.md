# Alternative B: Evidence-First Layout

Alternative B keeps the primary table central and adds collapsible evidence/context panels around it.

## Preview Intent

- Preserve current table-first workflows.
- Keep row order exactly as the page provides it.
- Make warnings clear, narrow, and limited to true review blockers.
- Move source context and caveats into predictable expanders.

## Pages It Could Help

- Rankings.
- Trading Lab.
- Development Lab.
- Settings / Data Health.

## Pros

- Least disruptive to the current UI.
- Strong fit for audit-heavy pages.
- Keeps power-user table scanning intact.

## Cons

- Still depends on dense tables for first comprehension.
- Expander defaults need care so evidence is discoverable but not noisy.

## Guardrail

The table remains a display surface. Alternative B must not add hidden sorting, change default rank logic, feed model inputs, or change source truth.
