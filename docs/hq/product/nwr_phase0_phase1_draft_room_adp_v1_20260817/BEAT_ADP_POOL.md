# Beat ADP Pool

Beat ADP intentionally separates value from timing.

NWR view uses the difference between owner ADP expected pick and the immutable NWR Redraft rank: `STRONG VALUE`, `VALUE`, `ALIGNED`, `FADE`, or `STRONG FADE`.

Draft timing uses the current pick, next owner pick, and admitted ADP evidence: `TAKE NOW`, `VALID`, `REACH`, `WAIT`, or `ADP UNAVAILABLE`. Roster fit, overall and positional tiers, recent position runs, and confidence remain visible context; none silently re-rank the NWR board.

With no imported snapshot, the Beat ADP table makes no market claim and the recommendation card explicitly says ADP is unavailable.
