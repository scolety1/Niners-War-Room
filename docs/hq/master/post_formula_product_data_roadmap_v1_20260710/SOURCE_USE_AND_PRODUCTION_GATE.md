# Source Use and Production Gate

No source is admitted or promoted. External research informed planning only. The immediate lane reads already-admitted metadata via existing services; unknown, stale, gated and unavailable remain distinct; no fallback, inference, backfill or name-only join. Scores, ranks, formulas, sorting, recommendations and eligibility remain unchanged. Frozen comparators stay review-only. Any need to edit a registry, ranking, formula, canonical export or freeze is a stop condition.
