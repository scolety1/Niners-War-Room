# Trading Lab Manual Review Packet Validation Expectations

Date: 2026-06-18

| example | expected_result | reason |
| --- | --- | --- |
| Packet with all required sections and public-source language | ACCEPT | Complete paper/research packet |
| Packet missing source/risk/paper sections | HOLD | Incomplete manual review |
| Packet with broker token language | REJECT | Credential/broker language |
| Packet with place-order language | REJECT | Execution language |
| Packet with account balance language | REJECT | Private account data |
| Packet asking for data ingestion or generated outputs | REJECT | Blocked workflow |

Validation is in-memory only and creates no output files.
