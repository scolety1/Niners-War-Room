# Trade integration

Mixed rookie/veteran packages receive two additional disclosed ordinal dimensions:

- **Immediate production context:** compares the best individual 2026 Redraft VBD on each side. It does not sum a side.
- **Medium-term research outlook:** compares the best individual frozen 3Y research signal, with LOW confidence and a research-only explanation. It does not sum a side.

If either side lacks required evidence, the dimension is `UNKNOWN`; missing never becomes zero. Existing Trade Decision Assistant synthesis remains ordinal. There is no hidden additive player or package score, and research-only evidence cannot silently become production authority.
