# Advanced Metrics NGS Surface Recommendation

Recommended:

- Development Lab: yes. Best review cockpit for metric context and caveats.
- Player Compare: yes. Side-by-side context can help Tim inspect player profiles without changing rankings.
- Data Health: yes. Coverage, source freshness, safe display counts, blocked counts, and thresholded missingness belong here.

Deferred or blocked:

- Rankings optional preset: maybe later, but deferred. No default sort or hidden sort is approved.
- Trading Lab: no for now. Too easy to read as trade advice.
- Live Draft / Mock Draft: no for now. Too easy to read as draft advice or ranking command.

The first runtime lane should be Development Lab plus Data Health or Development Lab plus Player Compare, not all surfaces at once.
