# Desktop owner flow

1. Open **Redraft → Profile & Scoring**.
2. Import Fantasy Gamers if it is not active.
3. Set the preferred temporary draft slot (2, 5, or 9) in the active profile and save.
4. Select **Start Practical Mock**. This makes one read-only Sleeper player-identity request and creates local manual K/DST assets.
5. Open **Draft Room**. Draft supported positions from NWR Fantasy Gamers Practical Rankings; use the K or DST filter to select any available manual asset.

The Weekly Tools Streamer remains optional. A missing FantasyPros key does not block Practical Mock.
