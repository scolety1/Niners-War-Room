# Cornerstone Retune Options

1. `multi_year_production_anchor`: build review-only rolling 2-3 year production and PPG anchors from admitted lagged factuals. This directly targets one-year overreaction.
2. `career_peak_or_ceiling_anchor`: preserve signal from demonstrated high-end seasons so elite players are not overly punished by one down or partial year.
3. `dynasty_cornerstone_floor`: use current NWR baseline tier/rank as review-only guard context, not as source truth, to keep cornerstone profiles from falling off a cliff.
4. `young_wr_te_stability_guard`: focus on WR/TE profiles with strong baseline cornerstone context and safe lagged production; do not use market, ADP, projections, routes, red-zone sidecars, or current injury/depth/schedule context.
5. `usage_lens_only`: retain the current candidate as a usage lens if retune evidence does not support main formula use.
6. `reject_current_board_formula_path`: reject if attribution continues to show structural cornerstone damage after a bounded stability retune.
