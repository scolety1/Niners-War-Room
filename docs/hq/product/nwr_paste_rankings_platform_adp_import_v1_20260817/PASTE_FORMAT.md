# Paste format

Paste a markdown pipe table with `Position`, `Player`, and any of `Consensus`, `Sleeper`, `ESPN`, or `FantasyPros`.

```text
| Position | Player | Consensus | Sleeper | ESPN | FantasyPros |
| --- | --- | ---: | ---: | ---: | ---: |
| RB1 | Player Name | 3.2 | — | 4.1 | 3.7 |
```

Blank, dash, and em-dash values are unknown, never zero.
