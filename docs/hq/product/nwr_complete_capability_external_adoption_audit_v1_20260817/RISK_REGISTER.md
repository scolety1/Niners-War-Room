# Risk Register

| Risk | Likelihood | Impact | Mitigation / gate |
|---|---|---|---|
| HQ and installed/candidate truth conflated | High | Critical | Phase 0 owner adoption with exact ancestry, hashes and state receipts |
| Silent authority promotion | Medium | Critical | Authority ledger, snapshot labels, regression fixtures |
| Dynasty installed binary lacks exact commit receipt | Known | Medium | Rebuild from adopted source after state-preserving owner acceptance |
| ADP source is unlicensed, stale or format-mismatched | High | High | owner CSV baseline; terms/freshness/coverage gate |
| Beat ADP probability overstates evidence | Medium | High | call heuristic a heuristic; calibrate before probability claims |
| CPU drafts mirror NWR rank | Current | High | ADP/history distribution, seeded tests and behavior diagnostics |
| Tier changes are unstable or cosmetic | Medium | Medium | position-first stability/perturbation tests and evidence boundaries |
| Weekly provider outage/staleness | High | High | immutable last snapshot, stale labels, graceful omission |
| Identity mismatch corrupts roster/availability | Medium | Critical | exact IDs, crosswalk receipts, UNKNOWN rather than fuzzy mutation |
| Sleeper mutation scope creeps in | Low | High | read-only adapter and architecture tests; owner executes actions |
| Paid API becomes operational requirement | Medium | High | optional adapter plus owner-import/offline fallback |
| Unlicensed repository code copied | Low | High | pattern-only records; separate license/code adoption review |
| Trade Finder invents a new score | Medium | High | call existing Trade Assistant; invariant regression tests |
| Owner state lost in upgrade | Low | Critical | atomic backups, migration dry-run, rollback and installed-state test |
| Scope expands to generic assistant/analytics | Medium | Medium | navigation/roadmap gates; defer non-owner-critical tools |
| External source terms change | Medium | High | provider registry with terms review date and kill switch |
