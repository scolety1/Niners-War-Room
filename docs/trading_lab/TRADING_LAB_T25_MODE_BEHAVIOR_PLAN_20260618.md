# Trading Lab T25 Mode Behavior Plan

Date: 2026-06-18

## Goal

Make the Trade Lab page feel different depending on selected fantasy trade
mode while staying fake-data only.

## Modes Covered

- Trade For Player
- Trade Away Player
- Upgrade Position
- Consolidate Depth
- Pick Conversion
- Drop-Pressure Trade
- Opponent-Fit Trade
- Training Mode

## Planned Behavior

Each mode gets a user question, explanation, relevant controls, warning
examples, and fake package/context data.

## Guardrails

No real data, real integrations, APIs, generated outputs, automated
decisioning, or Wall Street product framing.
