# What To Stop Testing

Stop active testing unless the user explicitly authorizes a new lane.

- Same-ingredient formula tuning
- Broad Formula Gauntlet reruns
- Review-only ranking simulation
- Production/model-use approval
- Rankings integration
- App/runtime behavior changes
- Source promotion
- Hidden sort or recommendation logic
- Canonical `local_exports` mutation
- Current-only ADP as historical input
- SportsDataIO / paid API / free-trial work
- PFF Elusive Rating
- `nwr_elusive_proxy_review_only`

Veteran decline / role-loss guard rules should not receive another refinement pass unless the user knowingly accepts the mixed result and authorizes a narrow second refinement.
