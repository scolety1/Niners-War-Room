# Market Context Consistency

Market context is joined by governed player identity after Finished V1 fields are loaded. Optional market rows can populate only market fields; they cannot overwrite player identity, rank, position rank, score, or value band.

The current artifact is stale and is presented as `Stale as of 2026-07-17`. Individual DP Value and DP Rank are shown where authorized. Trading Lab never totals the sides and never converts this evidence into a trade value model.

Verified examples: Luther Burden `4443 / 36.6`, Chuba Hubbard `538 / 126.4`, George Kittle `916 / 103.8`, Brock Purdy `2041 / 69.7`, and Puka Nacua `9076 / 6.2`.
