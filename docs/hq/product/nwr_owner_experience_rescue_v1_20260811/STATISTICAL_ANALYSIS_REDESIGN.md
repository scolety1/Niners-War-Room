# Statistical Analysis redesign

`Why NWR Ranks Them` is now a selected-player explanation. It reports admitted rank/score placement, the actual evidence fields carried by Finished V1, raw receipt values when present, qualitative effect (`HELPED`, `USED`, `RISK / CAP`, or context), exact admitted adjustment, reason/gate context, and owner-language caveats.

When a raw value or exact component contribution is absent from the frozen receipt, the UI says so. It never back-solves or invents weights.
