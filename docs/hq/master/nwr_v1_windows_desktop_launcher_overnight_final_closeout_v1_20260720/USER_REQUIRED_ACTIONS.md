# User required actions

1. Run the one-click receipt recovery from the final stable checkout as the real Explorer user and provide exact confirmation.
2. Run the one-click shortcut installer from that same account and provide exact confirmation.
3. Launch once, verify the expected browser/app-mode window, then use the installed Stop entry and confirm normal close.

Until steps 1-2 occur, the corrupt receipt remains preserved and no Desktop/Start Menu path is claimed installed.
