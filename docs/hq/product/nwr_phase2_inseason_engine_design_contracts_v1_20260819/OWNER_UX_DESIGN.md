# Owner UX design

Redraft: **Weekly** (start/sit), **Waivers** (adds/drops), **Streamers**, **Lineup**, **Roster Health**. Each answers one action question and displays source/freshness/confidence before a read-only recommendation.

Dynasty: **In-Season**, **Value Movement**, **Stash Watch**, **Trade Watch**, **Waivers/Stashes**. Each explains change versus existing authority; none presents a new dynasty universal rank.
