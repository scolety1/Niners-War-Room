# Usage Lens Vs Main Formula Decision

Current decision: keep the candidate as a review-only usage lens until a targeted dynasty-stability retune passes validation.

The candidate is useful because it finds current factual usage/opportunity/scoring signals. It is not ready as the main ranking formula because the current-board attribution still shows cornerstone/stability risk around elite WR/TE profiles. Market disagreement alone is not a blocker; the blocker is being low for the wrong reason, especially one-year overreaction.
