# Current UI Preservation Notes

## What Stays The Same

- Default rank logic stays unchanged.
- Production formulas stay unchanged.
- Model training and tuning stay unchanged.
- Source truth stays unchanged.
- Runtime data sources stay unchanged.
- Existing decision pages remain the source of the active app experience.

## What Users Already Like

- Fast access to Rankings, Player Compare, Trading Lab, Development Lab, Settings / Data Health, and Draft Room review sections.
- Direct table-first inspection for audit-heavy workflows.
- Clear review-only, display-only, and gate language.
- No marketing-style landing page in front of the work.

## What Should Not Be Disrupted

- No hidden sort.
- No recommendations.
- No source-truth promotion.
- No candidate formula output wired into default app pages.
- No default page behavior changes outside the clearly labeled preview route.
