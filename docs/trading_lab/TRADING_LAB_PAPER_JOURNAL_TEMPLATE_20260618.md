# Trading Lab Paper Journal Template

Date: 2026-06-18

## Purpose

This template is for paper and simulation-only Trading Lab journaling. It may
support learning, research discipline, and later paper simulation review. It is
not investment advice and creates no execution path, broker workflow, account
connection, credential storage, automated rule, generated output, or deployment
path.

Do not record real orders, private brokerage balances, broker exports, account
keys, API tokens, secrets, or automated execution rules.

## Required Fields

Each paper journal entry should include:

- `journal_id`
- `date`
- `symbol_or_topic`
- `asset_type`
- `research_question`
- `paper_action_type`
- `hypothetical_entry_reference`
- `hypothetical_exit_reference`
- `position_sizing_hypothesis`
- `risk_hypothesis`
- `invalidation_condition`
- `outcome_review_date`
- `lessons_learned`
- `status`
- `notes`

## Invalid And Prohibited Examples

These examples are invalid and must be rejected:

| prohibited_item | why_blocked |
| --- | --- |
| Real order placement | Real-money trading and broker orders are prohibited. |
| Broker account balance | Private account data is prohibited. |
| Private brokerage export | Private brokerage data is prohibited. |
| API key or token | Credentials, keys, tokens, and secrets are prohibited. |
| Auto-execute rules | Automated execution is prohibited. |

## Safe Use Reminder

Paper journal entries may describe hypothetical references and lessons learned.
They must not include personalized investment advice, live orders, private
balances, broker exports, credentials, secrets, automated triggers, or generated
market datasets.
