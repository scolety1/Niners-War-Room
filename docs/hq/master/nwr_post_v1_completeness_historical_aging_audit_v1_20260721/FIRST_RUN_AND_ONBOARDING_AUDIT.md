# First-run and onboarding audit

Before repair, the bare root executed Draft Cockpit. A first-time user landed in
a real local-state workflow before learning which surface was canonical,
read-only, manual, gated, or state-writing.

The root is now a dedicated read-only Start Here page with one H1, concise league
format, direct cards for Rankings, Compare, Trading, and Draft Cockpit, explicit
authority badges, and links to Data Health and Review Workflow. The existing
/draft-cockpit route is unchanged.

At 320x700, 375x812, 768x1024, and 1440x1000 the repaired root had one H1,
all primary links, no Page Not Found or traceback text, and no document-root
horizontal overflow. Opening it performs no provider call, ranking mutation,
draft mutation, refresh, recovery, or persistence write.
