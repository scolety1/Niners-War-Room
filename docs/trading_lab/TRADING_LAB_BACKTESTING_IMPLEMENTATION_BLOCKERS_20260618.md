# Trading Lab Backtesting Implementation Blockers

Date: 2026-06-18

## Purpose

This blocker list must be resolved before any future backtesting implementation
proposal can even be considered. This document does not approve implementation.

## Required Before Proposal

- Approved source inventory.
- Data licensing and terms review.
- Attribution plan.
- No credentials, secrets, keys, or tokens.
- No private brokerage/account data.
- Storage policy.
- Generated artifact policy.
- Validation plan.
- Explicit user/Master approval.
- No broker/execution pathway.
- No app/deployment coupling.
- Bias control plan.
- Non-advice labeling and closeout plan.

## Permanently Prohibited

- Real-money trading.
- Broker orders.
- Broker/API integration.
- Automated execution.
- Production investment advice.
- Private account data.

## Current Status

BLOCKED. No implementation has been approved.
