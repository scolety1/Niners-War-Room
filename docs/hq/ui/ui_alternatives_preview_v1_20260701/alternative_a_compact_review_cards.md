# Alternative A: Compact Review Cards

Alternative A tests whether the busiest review surfaces can open with compact summary cards before dense tables.

## Preview Intent

- Give Tim a quick first scan.
- Move detailed rows behind expanders or secondary sections.
- Use status badges for review-only, no rank change, gate status, and no verdict states.
- Improve mobile and desktop spacing with stable card dimensions.

## Pages It Could Help

- Rankings.
- Player Compare.
- Draft Room review sections.
- Settings / Data Health.

## Pros

- Reduces first-view density.
- Makes review state easier to read quickly.
- Works well on small screens.

## Cons

- Can hide useful audit detail if overused.
- Badge copy must avoid implying final decisions.

## Guardrail

Cards are display and review structure only. They must not compute recommendations, change rank order, change model output, or promote candidate formula output.
