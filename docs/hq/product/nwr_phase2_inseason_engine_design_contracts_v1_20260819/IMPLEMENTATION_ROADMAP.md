# Implementation roadmap

1. **2A shared substrate** — dedicated branch; Sleeper snapshots, availability, receipts/freshness; high risk; contract/property tests; no install.
2. **2B Redraft ROS/weekly** — separate branch; deterministic scoped values; provider gate and retrospective tests; owner evidence review.
3. **2C Redraft decisions** — waivers, drops, streamers, legal lineup; slot/availability/stale drills; owner weekly walkthrough.
4. **2D Dynasty in-season** — movement/stash/trade-watch only; preserve authorities; scenario and do-not-overreact tests.
5. **2E acceptance/package** — only after owner sign-off; isolated install/state-preservation acceptance.

No phase starts until provider and authority gates for that phase are approved.
