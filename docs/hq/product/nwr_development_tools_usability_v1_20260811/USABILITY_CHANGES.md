# Usability Changes

Date: 2026-08-11

## What changed

- Replaced raw comma-separated entry as the primary workflow with guided one-row forms.
- Kept a collapsed multi-row editor for experienced owners and backup recovery.
- Made commas inside names and notes CSV-safe, including quoted notes.
- Renamed the two vague lab tools to **Roster Planner** and **Future Pick Planner**.
- Organized Upcoming Draft Prep as seven numbered steps in the order an owner uses them.
- Replaced static deadline status tables with clickable checklists and visible progress.
- Put NFLVerse, source-policy, identity, refresh, and guardrail detail under Advanced.
- Reworded persistence around the owner action: Save your plan, Download backup, Import, Reset.
- Preserved local-only save behavior and explicit confirmation for reset/import operations.
- Updated navigation and related-tool links to use task language instead of lab language.

## Owner workflow

Each planning tool now follows the same pattern:

1. Understand the job from one sentence.
2. Add a roster item, pick, prospect, scenario, or note through labeled fields.
3. Review a compact owner-facing table or checklist.
4. Open Advanced only when technical context is needed.
5. Save locally or download a portable backup.
