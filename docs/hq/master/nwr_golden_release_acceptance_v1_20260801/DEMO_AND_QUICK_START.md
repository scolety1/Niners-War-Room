# Demo and Quick Start

1. Open Niners War Room and read the Start Here authority guidance.
2. Check Settings / Data Health before decision work.
3. Use Dynasty Rankings for the Finished V1 production board.
4. Use Asset Explorer to find typed current players, rookies, blockers, or picks.
5. Open the 2026 Rookie Board for Review-Only rookie evidence.
6. Use Player Compare for source-separated evidence and Trading Lab only as a
   manual descriptive workspace.
7. Enter Draft Cockpit only when intentionally managing local draft state.

Demo emphasis: source labels remain visible, rookie and veteran raw scores are
not equated, blocked rookies remain visible, and no surface automatically tells
the owner to accept or reject a move.
