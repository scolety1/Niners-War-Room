# Product contract
Production applies only to the shared 2026 Redraft comparison. Frozen research may supply an ordinal lean, never a price or production claim. Missing evidence is `None`/unavailable and never zero. Rookie Review Score and Finished V1 Score are shown only in their own evidence sections and never subtracted, averaged, normalized together, or used to manufacture a winner.
For exactly one veteran and one rookie, Player Compare automatically enters `ROOKIE_VETERAN` mode and returns decisions in this order:

1. `WIN NOW / 2026`
2. `DYNASTY TODAY`
3. `3-YEAR OUTLOOK`
4. `LONG-TERM`
5. `SAFETY`
6. `UPSIDE`
7. `UNCERTAINTY`

Allowed preferred values are a player name, `TOO CLOSE`, or `INSUFFICIENT EVIDENCE`. The interface badges each result as `PRODUCTION`, `REVIEW`, `RESEARCH ONLY`, or `INSUFFICIENT EVIDENCE`.
