# Preset Cleanup Summary

## Before

The Rankings page exposed these presets:

- Clean Board
- Market Analyzer
- Outcome Lens
- Data Review
- NWR Score Audit
- Compact Draft View

`Clean Board` showed market context by default, which made the default rankings view busier than desired.

## After

The Rankings page now exposes:

- Dynasty Review
- Market Context
- Outcome Context
- Data Review
- Statistic Analysis
- Draft Rankings

`Dynasty Review` is the default preset. It keeps Dynasty Rank primary, sorts by Dynasty Rank ascending, and hides market, Outcome, and injury-review detail columns by default.

`Market Context` is the explicit display-only DynastyProcess market view.

`Outcome Context` is the explicit display-only/review-only outcome and injury-context view.

`Statistic Analysis` is the read-only NWR Score metadata and feasibility view.

`Draft Rankings` replaces Compact Draft View.

The preset list intentionally does not add `Player Compare Prep` or `Roster Triage`.
