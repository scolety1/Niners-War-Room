# Parallel Chat Guardrails - 2026-07-09

- Keep each chat in its original purpose.
- Use fresh worktrees for repo work.
- State the exact base HQ commit before making artifacts.
- Do not touch dirty primary checkout state.
- Do not edit unrelated DynastyProcess docs.
- Do not run two lanes that edit the same review packet folder.
- Do not run two lanes that edit the same model, ranking, app, runtime, source-truth, or source-gate files.

- Every lane must preserve a source trace and final guardrail statement.

- No production rankings change.
- No active formula weight change.
- No formula activation.
- No default sort change.
- No hidden sort change.
- No app/UI integration.

- No source-truth promotion.

## Formula Gauntlet Blocks

- No challenger tournament.
