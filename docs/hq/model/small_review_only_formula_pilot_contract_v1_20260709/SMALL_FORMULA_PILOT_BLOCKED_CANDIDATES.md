# Small Formula Pilot Blocked Candidates

The small review-only pilot may not execute or imply any of the following:

- 100-candidate Formula Gauntlet.
- Full Formula Gauntlet tournament.
- Champion refinement.
- Optimized weights.
- ML model training.
- Formula winner selection.
- Production formula proposal.
- Hidden sort logic.
- Recommendation logic.
- Ranking integration.
- App/runtime/model behavior changes.
- Exact Model v4 historical replay.
- Production Model v4 replay claims.
- Route/YPRR/TPRR inputs.
- Return scoring inputs.
- Red zone inputs beyond separately caveated partial review-only context.
- Broad PFR feature expansion.
- PFR production use.
- PFF Elusive Rating.
- `nwr_elusive_proxy_review_only`.
- PFF-style elusive/proxy naming.
- Source promotion.
- Any current/future-only input.
- Any input without source/use-gate and leakage/as-of clearance.

Role archetype and age/lifecycle may not be used as direct ranking boosts, direct ranking penalties, production model inputs, or hidden sort inputs. They may only appear as review-only diagnostic slices, guarded candidate context, and formula-family context.

Confidence cap may only appear as caution/coverage context. It is not a formula feature.
