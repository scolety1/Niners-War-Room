# Model v4 Confidence Cap Use Gate Decision

## Maximum Allowed Use

`REVIEW_ONLY_COMPONENT_SIGNAL_TESTS`

## Allowed

- Master HQ evidence review.
- Data Hygiene source/receipt audit.
- Future narrow review-only component signal test contract.
- Coverage and missingness context in review-only analysis.

## Not Allowed

- Production/model-use.
- Source promotion.
- Formula Gauntlet tournaments.
- Exact Model v4 replay.
- Partial replay expansion without a separate approval.
- Rankings integration.
- App/runtime behavior changes.
- Tuning or optimizing weights.
- Production accuracy claims.

## Interpretation

The confidence-cap receipts can help answer whether coverage/missingness context has review-only historical signal. They cannot be treated as a model score or as proof that the Model v4 formula has historical accuracy.
