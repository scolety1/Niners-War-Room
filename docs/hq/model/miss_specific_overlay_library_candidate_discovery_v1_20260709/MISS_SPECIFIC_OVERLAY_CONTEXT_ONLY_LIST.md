# Miss-Specific Overlay Context-Only List

These overlay families should remain context-only unless a future bounded test proves net miss reduction without unacceptable collateral damage:

- `OVERLAY_005_VETERAN_ROLE_LOSS_PRIOR_PRODUCTION_TRAP`
- `OVERLAY_006_INJURY_AVAILABILITY_CAVEAT`
- `OVERLAY_007_LOW_SNAP_DEPTH_WARNING`
- `OVERLAY_010_POSITION_SPECIFIC_MISS_PATTERNS`

## Rationale

Veteran decline / role-loss testing was mixed. Injury and low snap/depth warnings are useful review signals but can create false negatives or suppress true rebounds. Position-specific overlays need more design work before testing to avoid small-sample fragmentation.

Context-only overlays may be reported in miss taxonomy and future readiness gates, but they should not alter scores, rankings, hidden sort, or recommendation logic.
