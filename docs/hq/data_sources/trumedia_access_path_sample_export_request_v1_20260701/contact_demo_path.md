# Contact Demo Path

Recommended route: email `info@trumedianetworks.com` and request a demo/evaluation conversation for NFL Advanced Analytics, NFL API, data warehouse, or partner export.

## Why This Route

- TruMedia's public pages position access for teams, media clients, and partners.
- TruMedia's public teams page identifies email as the path for demo or trial inquiries.
- TruMedia's terms require Customer License or written authorization before using services.
- TruMedia's public football page describes NFL Core, NFL Advanced Analytics, and NFL API, but does not provide a public self-service NFL signup.
- TruMedia's data warehouse page says third-party licensing rights affect access controls.

## Steps

1. Send `sample_export_request_email.md` to `info@trumedianetworks.com`.
2. Ask whether NWR should evaluate `NFL Advanced Analytics`, `NFL API`, the data warehouse, or a rights-cleared partner export.
3. Ask for a demo/trial under written evaluation terms before any credentialed access.
4. Prefer a vendor-generated sample export over API credentials for the first source-admission pass.
5. Request schema dictionary, field definitions, export timestamp, data license/use note, and explicit zero/missing semantics.
6. Ask whether PFF/GSIS IDs can be included, and whether a Sleeper ID crosswalk is available or permitted.
7. Ask whether NWR may store local derived artifacts and use them for private fantasy/dynasty formula research.
8. If TruMedia requires API evaluation, pause until credentials are provided by TruMedia through a secure channel and handled under `api_key_handling_policy.md`.

## Product Ask

Primary ask:

- `NFL Advanced Analytics`
- `NFL API`
- Data warehouse export
- Partner export that includes tracking, route, coverage, and ID fields

Secondary ask:

- Whether `NFL Core` can export any subset of play-by-play, player-game, player-week, route, alignment, or red-zone fields.

## Do Not Do

- Do not create a TruMedia account unless TruMedia approves a trial.
- Do not request or create an API key before rights are confirmed.
- Do not attempt login, scraping, endpoint discovery, credential reuse, or behind-login help documentation.
- Do not import any sample export into NWR app/model/runtime paths.
- Do not commit raw vendor data unless the Customer License explicitly allows repository storage.
