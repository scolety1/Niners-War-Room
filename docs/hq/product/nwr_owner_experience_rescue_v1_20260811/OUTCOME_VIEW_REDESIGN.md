# Outcome view redesign

Dynasty Outcomes is now position-first and one player per row. Each row contains every applicable threshold across `2026`, `2027`, `2028`, `Within 3Y`, `Within 5Y`, and `2 of 3Y`. Wrong-position columns are not created. Missing values display as a quiet em dash.

The coverage audit separates true evidence gaps, intentional blocks, loader/join issues, unsupported model cases, and stale/legacy issues. The canonical observed total remains 2,528 numeric values of 4,848 applicable values (52.1%); no probability was synthesized.
