# NWR V1 feature tour

## Start Here

The landing page routes work by intent: canonical Rankings, read-only Player
Compare, manual Trading Lab, explicit Draft Cockpit, Data Health, and the
review workflow.

## Research

- Dynasty Rankings: the accepted 240-row dynasty board.
- Player Compare: visible side-by-side context without mutation.
- Trading Lab: manual package planning; no automatic offer or persistence.

## Draft

- Draft Cockpit: explicit live local draft state.
- Mock Drafts: separate practice state.
- Draft Analyzer: recap and audit of local draft events.
- Upcoming Draft Prep: accepted checklist surface with caveats.

## Administration

- Settings / Data Health: truthful state and evidence status.
- Refresh Data: gated manual refresh controls.
- Recovery guidance: validates receipts and backup state without hiding errors.

## Development and review

Evidence and Development Lab surfaces are review-only. Manual roster tools stay
manual. Future Tools and legacy experimental surfaces are parked or
compatibility-only and must not be treated as production features.

See docs/user/screenshots/nwr_v1_20260722 for privacy-safe compact and desktop
walkthrough images of the eight primary surfaces.
